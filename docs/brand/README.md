# SETPIECE · freigegebenes Logo-Paket

Seit 29.10.2026 verwendet die App das von Vince bereitgestellte Paket aus `setpiece-logo/`: blauer Turm mit aufsteigendem Pfeil und SETPIECE/BY PERFORMIQ als Vektor-Schriftzug.

Die verwendeten Originale liegen in `artifacts/setpiece/public/images/brand/`. Auf dunklen App-Flächen erscheinen Symbol und weisser Schriftzug nebeneinander, ohne die Geometrie zu verändern. Das vollständige gestapelte Logo ist ebenfalls als SVG enthalten. BrandLogo bindet die Assets mit dem konfigurierten App-Basispfad ein.

Favicon, Apple-Touch-Icon, installierbare App-Icons und Open-Graph-Bild stammen unverändert aus dem gelieferten Paket. Die bestehende App-Funktionalität und Akzentfarbe wurden nicht neu gestaltet.

Die bisherigen Dateien `setpiece-mark-*` und `setpiece-logo-direction.png` in diesem Dokumentationsordner sind archivierte Entwürfe vom 28.10.; sie werden in der App nicht verwendet. Das gelieferte Logo ersetzt diesen grünen Entwurf.
