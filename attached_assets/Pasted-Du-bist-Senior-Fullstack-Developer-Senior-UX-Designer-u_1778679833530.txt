PHASE 1 — ROLE SUITABILITY ENGINE
────────────────────────

Erstelle eine neue zentrale Datei:

`artifacts/api-server/src/lib/roleSuitability.ts`

Diese Datei soll die Bewertungslogik für Rollen-Zuteilungen enthalten und später von Matchday, GhostMode, BoardHealth und Editor verwendet werden können.

Implementiere folgende Funktionen:

1. `normalizePlayerTags(player)`

Ziel:
Tags vereinheitlichen, weil im System unterschiedliche Tag-Namen vorkommen können.

Bitte mindestens folgende Normalisierungen unterstützen:

- `strong_header` und `best_header` → strong header
- `fast` und `fast_runner` → fast player
- `set_piece_specialist` und `delivery_specialist` → delivery specialist
- `strong_blocker`
- `rebound_hunter`
- `far_post_target`
- `goalkeeper`
- `defender`
- `midfielder`
- `forward`

Die Funktion soll ein Set oder Array mit normalisierten Tags zurückgeben.

2. `classifyRole(role, setPiece?)`

Ziel:
Rolle automatisch einem Archetyp zuordnen.

Nutze:
- role.name
- role.description
- role.coachingPoint
- optional setPiece title/type, falls vorhanden

Erkenne folgende Archetypen:

- `delivery`
- `aerial_target`
- `blocker`
- `runner`
- `rebound`
- `rest_defense`
- `defensive_marker`
- `counter_outlet`
- `generic`

Beispiele:
- delivery, taker, corner, freekick, Schütze → `delivery`
- target, header, flick, near post, far post, Kopfball → `aerial_target`
- block, screen, pick, sperren → `blocker`
- runner, run, decoy, attack space, Laufweg → `runner`
- rebound, second ball, zweite Bälle → `rebound`
- cover, rest defense, absicherung, sichern → `rest_defense`
- marker, marking, defend, zone, mannorientiert → `defensive_marker`
- outlet, transition, counter, konter → `counter_outlet`
